Ultrasonic Sensing — wide-beam range vs. LiDAR point cloud

One shared 360-degree environment, sensed by a wide ultrasonic cone that outputs a single distance number per ping, next to a dense LiDAR point cloud on the exact same scene — so the real tradeoff (near-zero spatial detail, but robust to lighting/dust) is visible directly. A pedagogical model, not a physically exact simulator — see README.md.
